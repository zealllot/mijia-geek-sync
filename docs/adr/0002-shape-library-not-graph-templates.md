# 用「形状库 + 代码拼装」，不用整图模板

规则由代码拼装：每种节点从真实规则图里抠一个样本当**形状**，生成器照着形状填值，
不手写节点也不整图套模板。每生成一条立刻 `xgg rule validate --body` 离线校验。

一开始的打算是「真图当骨架 + 占位符替换」，因为这个仓库踩过
「手写节点会被 schema 拒」的坑。但两户的实际图否掉了它：同一个「有人开灯」原型，
节点数从 12（电梯口，哑灯继电器）到 31（进门，9 个目标）不等 ——
`deviceOutput` 随目标数变，`varSetNumber` 随「有没有昼夜分支」变，`varGet` 随闸门数变。
要让整图模板表达这些，就得支持重复段、可选段以及**复制块之后重连边**，
那已经是自己写一个模板引擎了，而且最难的一步（重连边）正是模板帮不上忙的那步。

形状库保留了原来那条教训的价值（节点长什么样仍然来自真图，不是猜的），
`rule validate --body` 完全离线可跑（不连网关、不要 session），
所以拼错了在生成的当场就知道，不用等部署到别人家才发现。
